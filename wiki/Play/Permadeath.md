**Permadeath** is character death that reloading does not undo — when the character dies, the save reflects it, permanently. The convention traces to *Rogue* and the [[Roguelike]] lineage, where it was a decision rather than an accident of hardware. *Rogue* shipped with no save at all; when saving was added so a session could be broken off, players used it to reload away deaths, and the developers answered by making the game delete the save file the moment it was restored — an explicit anti-save-scumming measure, so the philosophy came first rather than being rationalised afterward. The genuine technical-limitation case is the arcade cabinet, which had nowhere to save to. The rule travelled intact into the [[Roguelike Deckbuilder]], where one bad draw can end a run exactly as one bad turn ends a classic roguelike's.

**Permadeath is not the same as a lost run.** A roguelike run that ends returns the player to a fresh start with the world reset; permadeath in a persistent game — an ironman mode, a hardcore server, a character built over months — destroys something a restart cannot regenerate, which is why ironman completions carry standing in [[Achievement Hunting]] far beyond anything the platforms grant them: Steam achievements are unweighted, and PlayStation's trophy tiers and Xbox Gamerscore are allocated by the developer, so an ironman badge's prestige comes from third-party rarity statistics rather than a platform reward. The behaviour permadeath defeats is save scumming: reloading before an unwanted outcome to erase it, available in any game with manual saves and exactly what a true permadeath rule removes.

The design argument underneath is that stakes require irreversibility — a threat the player can always undo is a delay, not a threat, the same case made for punishing, unroutable difficulty in [[Soulslike]] games. That argument is contested: [[Assist Mode]] toggles that soften or remove permadeath are now common, and pairing permadeath with [[Meta-Progression]] — rewards that survive the character's death — is the compromise most modern roguelikes reach for, converting loss into fuel for the next attempt and keeping the genre's [[Compulsion Loop]] running on a schedule closer to [[Variable-Ratio Reinforcement]] than to a stopping point.
