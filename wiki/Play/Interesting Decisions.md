Sid Meier, designer of *Civilization*, described a game as "a series of interesting decisions." The phrase became one of the most quoted ideas in game design, partly because it gives a test: if a choice isn't interesting, it might as well be automatic. He expanded on the idea in a 2012 talk at the Game Developers Conference.

His own example came from *Civilization*: whether a new city should build a granary, a temple, or a settler. Each has a clear benefit, none is always right, and the answer depends on the empire's situation and the player's plans. A hundred players facing the same choice grow a hundred different civilizations.

Decisions are uninteresting in several common ways:

- **Obvious.** One option is always best, so the choice is just a chore; see [[Dominant Strategy]].
- **Arbitrary.** Options have no visible consequences, so choosing is a coin flip.
- **Blind.** The player can't know enough to reason about them.
- **Irrelevant.** The choice doesn't change anything that matters later.

An interesting decision usually has a few features:

- **Trade-offs.** Each option costs something, such as time, resources, or another opportunity; see [[Opportunity Cost]].
- **Situational value.** Which option is best depends on circumstances, so the right answer changes from game to game.
- **Partial information.** Players know enough to estimate but not enough to be sure; see [[Perfect Information]] and [[Expected Value]].
- **Lasting consequences** that the player can see unfold.
- **Personal expression.** Different players can pick differently for their own reasons, such as playing defensively or taking risks.

Worker placement games are built on this, since every spot a player takes blocks the others; see [[Worker Placement]]. Engine builders offer a recurring choice between investing now and scoring now; see [[Engine Building]].

Common traps:

- **False choice in skill trees**, where one path is mathematically better and the others are mistakes; see [[Skill Tree]].
- **Illusion of choice in stories**, where branches quickly converge. Players often accept this if the choices feel personal, but notice when outcomes are identical; see [[Branching Narrative]].
- **Too many options**, which slows play and stalls players, a problem board gamers call analysis paralysis. Decision time grows with the number of options; see [[Hick's Law]]. Long sessions wear down judgment; see [[Decision Fatigue]]. Many players reasonably stop at a good enough option; see [[Satisficing]].

Meier's view has critics. Not every game is about decisions. Action games are often about execution, and many players enjoy simple, relaxing activities with no real choices. Richard Bartle's player types suggest that some people play to explore or socialize rather than decide; see [[Bartle Taxonomy]]. Frameworks that start from the player's experience rather than from choices make the same point; see [[MDA Framework]].
