**Mosaic** was a web browser released in 1993 by the National Center for Supercomputing Applications at the University of Illinois. It wasn't the first graphical browser, but it was the first that was easy to install, ran on the computers people actually owned, and showed pictures in the same window as the text. It did more than anything else to turn the [[World Wide Web]] from a tool for physicists into something the public used.

Marc Andreessen, an undergraduate working at the center, and Eric Bina, a staff programmer, wrote the first version for Unix workstations. Versions for Windows and the Macintosh followed within the year, and the center gave them away. Earlier browsers either ran on a single expensive machine or opened images in a separate window. Mosaic put them inline, using an image tag Andreessen proposed and then simply shipped; see [[HTML]] and [[GIF]]. Pages started looking like magazines rather than manuals.

It also smoothed over the rest of the early internet. Mosaic could browse [[Gopher]] menus and FTP sites as well as web pages, so users didn't need to know which system held a file. The same center wrote one of the first web servers and the convention for having it run programs, which made pages that responded to forms possible; see [[Common Gateway Interface]].

Use grew quickly. The web's share of internet traffic rose from a sliver to a large fraction within about two years, and more people published because more people could read; see [[Network Effect]].

Mosaic's descendants fought the next war:

- **Netscape.** In 1994 Andreessen left with the entrepreneur Jim Clark to found Mosaic Communications, renamed Netscape after the university objected. Its code was written from scratch. The internal name Mozilla, short for "Mosaic killer," is why nearly every browser still starts its identification string with that word; see [[User Agent String]].
- **Internet Explorer.** The university licensed Mosaic's code through a company called Spyglass, and Microsoft licensed it from Spyglass. The first versions of Internet Explorer said so in their About box.

Netscape and Microsoft then fought for the market; see [[Browser Wars]]. The university stopped developing Mosaic in 1997, by which time its own share of users had fallen to almost nothing. It had been free for academic and personal use, which helped it spread through university labs.

Much of what a browser does today traces to its choices: a single window mixing text and images, a back button, bookmarks, and an address bar that takes any kind of link; see [[Browser Engine]] and [[Hypermedia]]. So does the habit of shipping a feature first and standardizing it later, which shaped the web for the next decade; see [[Web Standards]].
